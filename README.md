# Sunflower

Una pequeña experiencia web interactiva para compartir una flor amarilla este 21 de septiembre.

## Características

- Ramo de girasoles ilustrado con SVG.
- Animaciones suaves y diseño responsive.
- Carta interactiva y lluvia de pétalos.
- Compatible con teclado y `prefers-reduced-motion`.
- Hecho únicamente con HTML, CSS y JavaScript.
